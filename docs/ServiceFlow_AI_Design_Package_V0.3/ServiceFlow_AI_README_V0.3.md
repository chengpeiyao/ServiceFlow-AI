## 最重要的调整

- AI 主任务从“推荐派工”改为“故障事实提取、关键追问、证据化排查建议”。
- AI 只允许客服确认结构化受理记录，不能修改合同、服务类型、SLA、团队和派工。
- P0 限定一个活动阻塞服务任务、固定 7×24 SLA；合同例外审批、并行任务和客户等待暂停后置。
- AI 建议的预期版本来自**模型实际读取**的业务快照，而不是模型返回后的最新版本。
- 用真实 MySQL 并发测试和 A0/A1/A2 模型对照来验证设计，不以文档完成代替实验结果。

## 状态

V0.3 是**拟定开发契约与静态 SQL 草案**；未执行 MySQL 建表、未编译代码、未调用云模型做效果实测。此包不是可部署的软件项目。前述 SQL 只用于新库初始化候选，不能当作 V0.2 已有生产数据的升级迁移。
