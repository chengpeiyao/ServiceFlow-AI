# S1-AI A3 混合受理候选与标签复核准备

日期：2026-10-20。结论：已实现并实测保守 A3 候选，但标签人工复核、逐事实语义评分和证据支持评分均未完成，不满足 S1-AI 效果验收或固定集开跑条件。

## 实现边界

A0/A1/A2 原有分类、检索、提示词正文与评分口径保持；A1/A2 继续使用 s1-ai-intake-v0.3。A3 使用独立 s1-ai-hybrid-v0.1 和 a3-conservative-v0.1，复用同一模型、参数、知识库、输出 Schema、严格校验及 20 秒超时/1024 输出 Token/有限重试。

A3 将 A0 的分类和追问字段计划传给模型，不传 gold、故障家族或案例 ID。模型可提供事实、候选推测、证据建议和问题表达；Java 强制使用规则分类和原追问字段集合。模型少写的问题使用原规则模板，模型增加的计划外问题被记录并排除。模型提供的同字段表达是否真正询问该字段，仍须人工判断。

模型完整输出必须先经过原校验。不合法时整份模型候选拒绝，保留 rawOutput/rawContent/validationErrors，明确记录 RULE_FALLBACK、modelStatus 和 modelCandidateAccepted=false；最终输出退回完整 A0，不清洗或修复非法模型事实。通过原校验的模型候选组合后再次校验。模型失败和重试的 Token、耗时、未知费用继续保留。

这是为了分离职责的保守实验。A3 继承 A0 的过宽问题集合、错误已知字段识别和漏问，既不保证覆盖所有标注必问项，也不宣称降低追问负担；未将“模型负责措辞”偷换为模型已经改善追问效果。后续规则策略应在标签复核后单独版本化比较。

## 标签与人工评分

已为 20 条开发案例生成 [逐案例标签复核底稿](../../experiments/s1-ai/review/dev-label-audit-v1.jsonl) 和 [字段口径说明](../../experiments/s1-ai/review/README.md)。包含 D-05 故障后重试是否能归 change、D-04 最后心跳是否能归 startTime、D-15 否定报错、D-16 版本冲突短语等争议。所有行仍为待人工复核，没有据此改标签或补填审核人。

新证据提供 fact-semantic-review.jsonl，原始候选与最终输出逐事实记录原文、值、引文机械检查和待填字段语义/值语义评分。案例级 human-review.jsonl 仍全部 NULL。A3 人工表审核最终组合结果，原始模型候选在 results.jsonl 和逐事实表中独立保留。原精确匹配分数和来源拒绝不放宽，不能把底稿生成说成人工验收完成。

另做了问题文本的逐字比较：A3 最终 139 个问题全部与同批 A0 同字段规则模板完全相同，其中 5 个来自规则降级，134 个来自通过校验的模型候选。也就是说，本候选并未在可观察的文字层面实现“具体、自然的改写”，却增加了模型延迟和用量。ruleDecision 提供了完整模板，可能促使模型直接照抄，因此这一结果只否定当前候选已产生收益，不能据此断言模型没有改写能力；本轮不根据结果继续修改 Prompt 重跑。比较明细见 [问题文本核对](../../experiments/s1-ai/evidence/dev-a3-v01-2026-10-20/question-wording-check.json)。

本轮 A3 的事实精确匹配 F1 为 0.2973，低于 A0 的 0.3291，也未解决必问覆盖和标注外负担。当前额外模型成本没有对应的已验证收益，不建议把本候选接入业务或写成简历中的效果提升。

## 验证与后续门槛

`scripts/Test-Project.ps1 -Offline` 执行独立真实 MySQL 的 clean verify：65 项测试通过，失败/错误/跳过均为 0，含原 S1 27 项、原实验 32 项及 A3 新增 6 项。A3 测试覆盖规则字段控制、原始输出不变、非法事实整份拒绝、传输失败降级、用量保留及模型输入无标签。假 HTTP 仅验证工程行为，不当作模型效果证据。

1. 由人工复核字段定义和 20 条标签；先做争议记录，再决定是否创建新数据版本。
2. 填写本轮案例与逐事实语义表，特别区分来源正确/字段错误、必问遗漏、标注外合理追问和不合理负担。
3. 若调整标签、问题规则或 Prompt，记录新版本并在同一数据版本重评全部候选，不能跨版本混算。
4. 冻结配置后才安排固定检查集；本轮不自动执行。若发现规则足够，允许移除没有增益的模型职责。

本轮不改系统整体架构，不接业务写入，不增加前端、工作流或模型规模。
